# 📌 Sticky Notes Desktop (윈도우 데스크톱 포스트잇)

React와 Tailwind CSS로 제작된 윈도우 PC 데스크톱 스타일의 인터랙티브 스티커 메모 웹 애플리케이션입니다.

---

## 🚀 빠른 시작 (설치 없이 즉시 실행)

Node.js나 빌드 도구 없이 브라우저에서 바로 사용하실 수 있습니다.

1. 탐색기에서 아래 경로로 이동합니다:
   ```
   C:\Users\user\.gemini\antigravity\scratch\postit-notes\index.html
   ```
2. **`index.html`** 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 웨일(Whale) 등 선호하는 브라우저로 엽니다.
3. 바탕화면에 바로 포스트잇 스티커 메모장이 실행됩니다!

> **팁**: 브라우저에서 `F11`을 누르면 전체화면으로 실행되어 실제 윈도우 데스크톱 바탕화면 포스트잇처럼 사용하실 수 있습니다.

---

## ✨ 주요 기능

### 1. 직관적인 메모 관리 (C.R.U.D & UI)
- **자유로운 드래그 앤 드롭**: 메모 상단의 헤더 바를 마우스로 잡고 캔버스 내 원하는 위치로 부드럽게 이동.
- **마우스 드래깅 메모 크기 조절**: 우측 하단 코너의 리사이즈 핸들을 잡고 드래그하여 가로/세로 크기를 원하는 대로 자유롭게 조절 (조절된 크기 자동 저장).
- **메모장 하단 삭제 탭**: 각 메모장 하단 툴바에 직관적인 [🗑️ 삭제] 탭 버튼을 제공하여 원클릭으로 안전하고 간편하게 메모 삭제.
- **클릭 시 최상단 배치 (Z-Index)**: 클릭하거나 이동 중인 메모가 자동으로 최상단으로 올라옵니다.
- **새 메모 추가 (+)**: 상단 작업표시줄의 [+ 새 메모 추가] 버튼 또는 각 메모 헤더의 (+) 버튼으로 즉시 생성.
- **접기/펼치기 & 핀 고정**: 메모 최소화 및 상단 고정 지원.
- **안전한 삭제**: 상단 헤더의 닫기 버튼 및 하단 툴바의 [삭제] 탭 버튼 모두 지원.

### 2. 콘텐츠 및 링크 / 미디어 첨부
- **텍스트 실시간 편집**: 인라인 제목 및 본문 자동 줄바꿈.
- **외부 웹사이트 링크**: 외부 URL 추가 시 클릭 가능한 링크 칩이 생성되며, 클릭 시 새 탭(`target="_blank"`)에서 열림.
- **로컬 사진/이미지 첨부 및 미리보기**: 
  - 사진 파일 첨부 시 썸네일 그리드가 생성됩니다.
  - 썸네일을 클릭하면 대형 라이트박스(Lightbox) 뷰어로 고화질 확대 미리보기가 가능합니다.
  - 드래그 앤 드롭으로 이미지를 메모 위에 바로 끌어다 놓아 첨부할 수 있습니다.
- **로컬 파일 첨부**:
  - 문서나 압축 파일 등 다양한 로컬 파일 첨부 지원.
  - 파일명, 용량 배지 표시 및 원클릭 다운로드 기능 지원.

### 3. 디자인 커스터마이징
- **7가지 파스텔 컬러 테마**:
  - 💛 레몬 옐로우, 💖 베이비 핑크, 💚 프레시 민트, 💙 스카이 블루, 🧡 소프트 오렌지, 💜 라벤더 퍼플, 🤍 클라우드 화이트
- **폰트 및 스타일 변경**:
  - 기본 고딕(Sans), 감성 손글씨(Gaegu/Cursive), 명조체(Serif), 코딩체(Mono)
  - 글자 크기: 작게(Small), 보통(Medium), 크게(Large)

### 4. 데이터 영속성 (localStorage)
- 브라우저를 새로고침하거나 닫아도 모든 메모 내용, 위치, 첨부파일, 디자인 설정이 `localStorage`에 자동 보관됩니다.
- **JSON 백업 및 복원**: 상단 바의 백업(Save) 버튼으로 JSON 파일 다운로드, 복원(Upload) 버튼으로 손쉽게 이전 데이터 불러오기 가능.
- **바둑판식 자동 정렬**: 한 번의 클릭으로 흐트러진 포스트잇을 화면에 바둑판식으로 깔끔하게 정렬.

## 🛠️ 기존 React 프로젝트 (Vite / Next.js)에 연동하기

`StickyNotesApp.jsx` 파일을 기존 React 프로젝트의 컴포넌트 폴더로 복사한 뒤 아래와 같이 불러옵니다:

```jsx
import StickyNotesApp from './StickyNotesApp';

export default function App() {
  return (
    <div className="w-full h-screen">
      <StickyNotesApp />
    </div>
  );
}
```

*필요 패키지*:
```bash
npm install lucide-react
```
